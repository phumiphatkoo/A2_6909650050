เว็บไซต์นี้เวลาเปิดบนเครื่องจะมี Client เกิดขึ้น แต่ไม่มี Web Server เพราะเว็บไซต์ทำการเปิดผ่านทางไฟล์ข้อมูลโดยตรง

How I Built It

  1. เขียนโค้ดโดยใช้โปรแกรม Visual Studio Code เพื่อสำหรับเริ่มสร้างเว็บไซต์และสำหรับใช้เปิดดูผลลัพธ์ผ่านเว็บ Browser

  2. เริ่มสร้างโครงสร้าง HTML โดยการเขียนโครงสร้างหลักและเนื้อหาต่างๆลงในเว็บไซต์

  3. สร้างไฟล์ CSS ใช้สำหรับออกแบบและตกแต่งเว็บไซต์

Reflection

  1. สิ่งที่ท้าทายคือการได้เรียนรู้การสร้างเว็บไซต์ด้วยระบบการทำงานของ HTML และ CSS โดยจะพยายามเรียนรู้ระบบการทำงานให้มากขึ้นเพื่อให้ได้ผลงานที่ดีที่สุด

  2. จากการทำเว็บไซต์ครั้งนี้ ทำให้เข้าใจถึงหน้าทึ่การทำงานของ HTML คือการสร้างโครงสร้างของเว็บไซต์ และ CSS คือการตกแต่งจัดองค์ประกอบของเว็บไซต์

  3. หากต้องพัฒนาเว็บไซต์นี้ต่อ ต้องเรียนรู้การจัดโครงสร้างของเว็บไซต์ให้ดูเข้าใจง่าย ไม่ซับซ้อน และพัฒนาการใช้ CSS ในการตกแต่งเว็บไซต์ให้ดูมีมิติ ทันสมัยและสวยงามมากขึ้น ให้เหมาะกับการใช้งาน

โครงการ Thailand Metaverse Workshop จุฬาลงกรณ์ มหาวิทยาลัย

Type : Activity

Date : 22 Feb 2025

Role : Participant

Description : ได้ร่วมทีมทำ workshop เขียนโปรแกรม Unity ในงาน Thailand Metaverse จุฬาลงกรณ์ มหาวิทยาลัย เพื่อคนหาผู้ชนะเลิศการแข่งขันเขียนโปรแกรมสร้างเกม

Skills : Communication, Teamwork, Programming, Modeling, Unity, Blender

Reflection :

  1. ได้รับใบประกาศนียบัตร "เข้าร่วมทำกิจกรรมอย่างสำเร็จ (Successfully participate)" ในเวิร์กชอปที่จัดขึ้นเมื่อวันที่ 22 กุมภาพันธ์ 2025 เพื่อนำไปเป็นใบเซอร์ในการยืนยันการเข้าร่วมอบรม และสามารถนำไปต่อยอดในการทำงานการเขียนโปรแกรมต่อไป

  2. ได้เรียนรู้และฝึกฝนทักษะผ่านเวิร์กชอปด้าน Metaverse ซึ่งเป็นเทคโนโลยีแห่งอนาคต ร่วมกับผู้เชี่ยวชาญ

  3. ได้เรียนรู้ทักษะและความรู้ทางเทคนิค (Technical Skills) การใช้ Blender สร้างโมเดล 3 มิติ: ได้เรียนรู้วิธีขึ้นรูปโมเดล ออกแบบวัตถุ หรือสภาพแวดล้อม 3D ตั้งแต่พื้นฐานจนสามารถนำไปใช้งานได้จริง

  4. ได้เรียนรู้การเขียนโปรแกรมและประกอบโลกด้วย Unity โดยได้ฝึกนำโมเดล 3D จาก Blender มาใส่ในโปรแกรม Blender Unity จัดการสภาพแวดล้อม และใส่สคริปต์เพื่อให้โลกเสมือนจริงขยับหรือโต้ตอบได้

  5. มีความเข้าใจเรื่อง Metaverse Ecosystem: เห็นภาพรวมการเชื่อมโยงระหว่างงานออกแบบ 3D, การพัฒนาโปรแกรม และการประยุกต์ใช้เทคโนโลยีโลกเสมือนในอนาคต

  6. ประสบการณ์และการทำงานเป็นทีม (Soft Skills & Experience)

กระบวนการ Hackathon แบบเข้มข้น: ได้ฝึกแก้ปัญหาเฉพาะหน้า การบริหารเวลา และการระดมความคิด (Brainstorming) ร่วมกับสมาชิกในทีมภายใต้ความกดดันและกรอบเวลาจำกัด
